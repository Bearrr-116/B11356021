服務對象

-  再轉1  **一般民眾電話法律諮詢專線**
如民眾**有勞工、家事、債務清理**與**原住民**等類型的法律問題，可來電法律諮詢。

-  再轉2  **身心障礙者電話法律諮詢專線**
如您為身心障礙者，不限案件類型，均可來電法律諮詢。*（**更多身心障礙者法扶之服務，請連結：*[***法扶會******CRPD******身心障礙者無障礙網站***](https://crpd.laf.org.tw/)*）*

-  再轉3  **助人工作者電話法律諮詢專線**
當社工或其他助人工作者（例如通譯員、手語翻譯員等），在工作上遇到個案有法律問題，不限任何範圍，均可來電法律諮詢。

-  再轉5  **犯罪被害人電話法律諮詢**
凡為犯罪事件之被害人，不限身分類別，例如因遭人縱火房屋毀損、家暴被害人等等，只要是因他人的犯罪行為導致受害，均可來電法律諮詢。*（**請連結司法院網站：*[***犯罪被害人及告訴人訴訟權益告知書***](https://www.judicial.gov.tw/tw/cp-80-500755-1a42c-1.html)*）*

-  再轉6  **租屋糾紛承租人電話法律諮詢**
住宅租賃承租人（房客）因住宅租賃關係與出租人（房東）發生法律爭議，例如遭房東提前終止租約或不當扣抵押金、對於租屋處電費計費收取方式有爭議等，均可來電法律諮詢。

服務費用

- 免費諮詢，您不需要負擔律師費，由法扶基金會支付律師諮詢費。

- 特別提醒本專線以市話計費，若以手機撥打，請留意各電信業者之計費。

注意事項

- 諮詢律師提供諮詢服務時，會請您提供一些基礎個資，為維護雙方權益，諮詢過程將會錄音存檔，經諮詢律師繕打製作之諮詢紀錄及錄音檔案，由本會依個人資料保護法及相關法令保存及處理（可參本會官網公開資訊[**隱私權保護政策**](https://www.laf.org.tw/term)）。 

- 為方便其他民眾使用，「一般民眾」及「犯罪被害人」及「租屋糾紛承租人」法律諮詢專線通話時間限20分鐘；「身心障礙者」及「助人工作者」法律諮詢專線通話時間限30分鐘。

- 依民眾詢問內容及繁簡程度，提供分流服務：

- 民眾詢問之問題，均直接由諮詢律師直接回答。

- 民眾詢問之法律問題，如無法僅以電話諮詢時，本專線可線上直接為民眾預約面對面法律諮詢時段。

- 民眾如欲向分會申請扶助時，亦會告知分會電話等資訊。

現場法律諮詢

發佈日期：2023.12.18

更新日期：2026.05.27

1.服務說明

法律扶助基金會與各縣市單位合作並提供法律諮詢駐點服務，您可以在法律諮詢駐點，與專業律師面對面進行「現場法律諮詢」，每位民眾限時20分鐘。
 

2.服務對象

只要是在台灣的民眾，均可使用法扶基金會法律諮詢服務，且不需要審查您的資力（即財力）及案情。

3.諮詢費用

免費諮詢，您不需要負擔律師費，由法律扶助基金會支付律師諮詢費。
 

4.應備文件

建議攜帶預約面談者的身分證（或其他身分證明文件）、案情相關資料。
 

5.預約方式

請透過下方篩選器查詢預約方式，網路預約請連結[「法律扶助線上預約系統」](https://legal-advice.laf.org.tw/)進行線上預約。

如線上預約系統內沒有您可配合的時間地點，敬請透過下方「服務駐點查詢功能」，另外洽詢或查找可配合的服務時段及預約方式。

 

6.服務駐點查詢

請透過下方篩選器查詢，或點擊連結開啟或下載：[**「現場面對面法律諮詢駐點一覽表」****.ods**](https://www.laf.org.tw/upload/user/files/%E6%B3%95%E5%BE%8B%E6%89%B6%E5%8A%A9%E5%9F%BA%E9%87%91%E6%9C%83%20%E7%8F%BE%E5%A0%B4%E9%9D%A2%E5%B0%8D%E9%9D%A2%E6%B3%95%E5%BE%8B%E8%AB%AE%E8%A9%A2%E4%B8%80%E8%A6%BD%E8%A1%A82026.05.27.ods)
